统计口径

包含 HTTP、WebSocket、TLS、随机白噪音与通道重发的 TCP 字节，不含 TCP/IP 包头及业务端口。服务端包含同端口管理流量，客户端不含独立管理端口流量。

QUIC 隧道按流字节计数，不含 QUIC/TLS、UDP/IP 开销及 QUIC 重传；不能直接作为线上带宽对比。

WS/WSS 白噪音大小表示每批负载；QUIC 表示每秒负载速率，并按小帧平滑发送。每条隧道独立计速；协议开销不包含在配置速率中，暂停或拥塞后不补发积压额度。
